# Dyson Cube Project Addon 1.0.25

## 中文

### 修复

- 完善英文语言环境下的本地化，移除运行时提示、按钮和状态消息中的硬编码中文。
- 星体名称改为使用语言包显示，英文环境下不再直接显示中文星体名。
- 补齐反物质、鸿蒙之气、寰宇之心、黑洞增幅器和相关指令反馈的中英文文本。
- 保留旧存档中的星体名称字段和数据格式，已有存档可以继续使用。

### 改进

- 保留并整合 AE 风格的数量缩写：`K`、`M`、`G`、`T`、`P`、`E`。
- 戴森终端和相关界面继续使用紧凑数量显示，悬浮提示保留更完整的精确值。
- 新增中英双语攻略 `GUIDE_BILINGUAL.md`，涵盖安装、核心流程、存储系统、寰宇之心和性能排查。

## English

### Fixes

- Completed localization for English players and removed hard-coded Chinese from runtime messages, buttons, and status displays.
- Star names now use language entries instead of displaying the raw Chinese names stored by older data.
- Added English and Chinese translations for antimatter, Primordial Qi, Cosmic Heart, Black Hole Amplifier, and command feedback.
- Kept the legacy star-name field and save-data format so existing worlds remain compatible.

### Improvements

- Retained AE-style compact number units: `K`, `M`, `G`, `T`, `P`, and `E`.
- Dyson Terminal and related screens continue to use compact values while tooltips provide a more complete exact value.
- Added `GUIDE_BILINGUAL.md`, a Chinese/English guide covering installation, the main progression, storage, Cosmic Heart rewards, and performance troubleshooting.
