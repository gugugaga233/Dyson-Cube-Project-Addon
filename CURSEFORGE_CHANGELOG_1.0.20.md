# Dyson Cube Project Addon 1.0.20

## 中文

- 修复 `1.0.19` 启动时的 Mixin 崩溃。
- 移除针对原模组不存在的 `processStructureReserve` 方法注入；原模组 `1.0.5` 的电磁轨道弹射器现在可以正常完成类转换。
- 保留 `1.0.19` 的超大压缩材料结算优化、有限结算上限和时间预算续算逻辑。
- 更新 NeoForge 模组元数据版本至 `1.0.20`。

## English

- Fixed the Mixin crash introduced during startup by `1.0.19`.
- Removed the injection targeting `processStructureReserve`, a method that does not exist in the original mod `1.0.5`; EM Rail Ejector class transformation now completes normally.
- Preserved the huge-compression settlement optimization, finite settlement limit, and time-budget continuation logic from `1.0.19`.
- Updated the NeoForge mod metadata version to `1.0.20`.
