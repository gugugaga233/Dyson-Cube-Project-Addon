# Dyson Cube Project Addon 1.0.18

## 中文

- 修复寰宇之心奖励界面的 `MAX` 按钮在已生效过的可重复词条上点击无反应的问题。
- `MAX` 现在会正确清空其他分配，并将本次全部奖励次数填入所选词条。
- 同步修正 jar 内部 NeoForge 模组版本号，CurseForge 启动器会正确显示 `1.0.18`。

## English

- Fixed the Cosmic Heart reward `MAX` button doing nothing on repeatable rewards that had already been applied before.
- `MAX` now correctly clears the other allocations and assigns the full current reward count to the selected entry.
- Synchronized the internal NeoForge mod metadata so CurseForge displays version `1.0.18` correctly.
